# Privacy Policy

**Last updated:** 2026-05-16

This GitHub App ("the App") is committed to user privacy.

## 1. No personal data collection

The App does not collect, store, or transmit any personal data of users. All processing occurs within GitHub Actions runners owned by the repository where the App is installed.

## 2. Data accessed

The App accesses the following data, granted by its installation permissions:

- Pull request metadata (title, body, author, branch names) — read only, to identify the PR to approve
- Repository code and metadata — read only, to satisfy the GitHub App permission requirements

No data is stored persistently by the App itself. No data is transmitted to any third party.

## 3. GitHub's role

All data flows are mediated by GitHub APIs and subject to [GitHub's Privacy Statement](https://docs.github.com/en/site-policy/privacy-policies/github-privacy-statement).

## 4. Logs

Execution logs are stored in GitHub Actions runner logs of the installing repository, retained according to that repository's settings. The App does not maintain its own log storage.

## 5. Removal

Uninstalling the App removes its access to the repository immediately. No data persists outside GitHub after removal.

## 6. Changes

This privacy policy may be updated at any time. Updates are committed to the public source repository.

## 7. Contact

For privacy-related questions, please open an issue at <https://github.com/hirokimry/vibehawk/issues>.
